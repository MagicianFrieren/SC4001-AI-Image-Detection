多生成器质量门控实验结果（2026-11-08）

结论
本次实验没有证明“让门控多见一种生成器，就能提高对另一种生成器的识别能力”。
固定专家、固定样本数后，多来源质量门控的平均 AUROC 为 0.620198，低于简单平均融合的 0.624427，也低于同规则重跑的单来源质量门控 0.624399。三个数据 seed 的上述差值均为负。不能将这次尝试报告为主指标上的小幅改进。

研究问题与对照
门控根据两个专家的输出和图片质量特征，决定当前图片更应该相信哪个专家。本轮检验的具体假设是：此前门控只接触 SD1.5 假图，学到的融合规则不能迁移；增加一种生成器用于拟合和选择，能否改善迁移？

两折分别为：
  SD1.5 + ADM 用于拟合/选择，评估未参与该折拟合/选择的 BigGAN；
  SD1.5 + BigGAN 用于拟合/选择，评估未参与该折拟合/选择的 ADM。

单来源拟合：250 Real + 250 SD1.5 原图。
多来源拟合：相同 250 Real + 125 SD1.5 + 125 donor 原图。
单来源选择：124 Real + 124 SD1.5 原图。
多来源选择：相同 124 Real + 62 SD1.5 + 62 donor 原图。
因此处理改变的是生成器构成，而不是图片总数；同时改变了拟合和选择分布，不能解释为仅训练数据的因果效应。

现有 Round 8 A matched 全局/局部专家均冻结。两组都使用原图视角的缓存特征和专家分数。训练与选择使用 clean、JPEG70、resize05；另外报告 JPEG50。每折评估 300 张留出生成器图片和 300 张独立 development Real 原图。不同图像处理视角始终随原图分组。
使用三个数据 seed（20261101/2/3）、三个门控初始化 seed（20261022/3/4），共 54 次拟合。门控结构及训练超参数不变。每条训练轨迹同时保存 AUROC 与 BCE 选择的检查点；预先指定 AUROC 检查点为主分析，BCE 为次分析。固定权重融合在相同选择数据上从 0,0.1,...,1 选择权重。所有模型及设置在评估留出生成器前冻结。

主结果
先平均同一数据 seed 内的门控初始化指标，再等权平均三个数据 seed、两个生成器和四种处理条件。AUROC 越高越好；0.5 为无区分能力的参考。它不是准确率。

这里的单来源质量门控是本轮同规则重跑的对照，并非直接引用历史实验的旧检查点。
多来源质量门控相对单来源质量门控，三个数据 seed 的 AUROC 差值依次为 -0.006505、-0.000906、-0.005194。

局部效果与损失
以下为多来源质量门控相对多来源简单平均融合的 AUROC 差值，正值表示门控更好：

留出生成器       clean       JPEG70      JPEG50      resize05
ADM             +0.005177   -0.011523   -0.011119   +0.013984
BigGAN          -0.011044   -0.019431   -0.020433   +0.020554

两种生成器的缩小图片都有局部收益，但不足以抵消 JPEG 下的损失；这两项 resize 条件下全局专家单独使用仍高于质量门控。质量门控相对普通门控，在两个生成器、两个 JPEG 条件、三个数据 seed 共 12 个单元中全部下降。这提示当前质量输入带来的融合规则在压缩图片上的迁移需要重点检查；它不是已经证实的失败机制。

多来源质量门控相对单来源质量门控的 AP 与平衡准确率有所上升，但 Real 误报率也从 15.40% 增加到 18.87%。相对多来源平均融合，三个次要指标均值有利于质量门控；这些是应保留的指标取舍，不能事后取代 AUROC 主目标。各方法阈值只由其所属组的选择数据确定，固定应用于所有评估条件。平均融合两组的分数完全一致，阈值差异可导致平衡准确率和误报率不同。

不确定性
使用 1000 次按类别分层、按原图配对的 bootstrap，所有方法、条件和 seed 使用同一组身份抽样，两个目标生成器共享 Real 抽样。95% 条件百分位区间：
  多来源质量门控 - 平均融合：          [-0.008963, +0.000857]
  多来源质量门控 - 多来源固定融合：    [-0.002548, +0.001864]
  多来源质量门控 - 多来源普通门控：    [-0.005270, -0.000579]
  多来源质量门控 - 单来源质量门控：    [-0.008749, +0.000696]

与平均融合、单来源质量门控的区间跨零，不能称确定变差，但没有支持改善的证据。区间以已经拟合的模型为条件，不涵盖重新采样训练数据并重训或未来生成器的不确定性；多个探索比较未校正。三个 seed 共享数据池，不能视为三个独立数据集。
BCE 选择也没有挽救主结论：单来源/多来源质量门控 AUROC 分别为 0.602049/0.602254。

验证与范围
预检通过身份分区、重复图片和缓存一致性检查。独立验证已核对 664 个哈希、54 次拟合及 108 个检查点，重新计算 460800 条预测对应的 768 个逐初始化指标单元和 384 个逐 seed 指标单元，最大指标误差为 2.22e-16。独立 NumPy 重建门控权重，最大 alpha 差 7.75e-7；源分数、9 个固定权重网格及 36 个基线阈值精确重建。bootstrap 文件校验和已核对，但区间没有独立重放；门控阈值与保存设置及预测一致，独立阈值重算只覆盖基线。

本轮属于此前已查看过的 development 生成器上的探索性留出评估，不是新的盲测。未读取最终/保留测试集的图像、分数或清单。不能据此断言所有多来源门控都无效，也不能称项目已获得泛化性能改进。

对研究假设的回答
在本次固定专家、固定样本数和两折设定下，仅让质量门控多接触一种生成器不足以带来主指标改进。已有证据定位到跨生成器 JPEG 条件下的一致损失，但尚不能断定这是质量特征、专家能力或训练目标中的哪一项单独造成的。
